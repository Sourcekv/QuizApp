# QA Quiz App

A React + Vite practice quiz for QA Unit 4 - Business Requirements Document and QA Unit 5 - User Stories and Use Cases.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Push this clean project to GitHub. Do not commit `node_modules`, `dist`, or `.git` folders from copied archives. Vercel will install dependencies and build the app automatically.
